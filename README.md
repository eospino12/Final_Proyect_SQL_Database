Chicago Crime & Census SQL Analysis

Final project developed as part of the IBM SQL and Databases coursework.
This project focuses on exploratory data analysis using SQL over multiple datasets related to Chicago census information, public schools, and crime records.

The workflow included:

Loading CSV datasets into a SQLite database using Python and Pandas.
Creating and managing relational tables in SQLite.
Writing SQL queries to solve analytical problems involving:
aggregation functions,
subqueries,
filtering,
grouping,
ordering,
joins and data exploration.

Datasets used:

Chicago Census Data
Chicago Public Schools Data
Chicago Crime Data
Technologies Used
Python
Pandas
SQLite
Jupyter Notebook
SQL
Features
Automated ingestion of CSV datasets into SQLite tables.
SQL-based analysis of crime statistics and socioeconomic indicators.
Community area analysis using subqueries and aggregate functions.
Educational project demonstrating practical database querying skills.
Frontend Visualization

A frontend interface was additionally created using AGY to visualize and interact with the processed analytical data generated from the SQL queries.

Through this project, the following concepts were reinforced:

SQL query design
Database manipulation
Data aggregation and filtering
Subqueries
SQLite integration with Python
Data analysis workflows using Jupyter
